## Install Into A Project

Extract the ZIP, then run this from the extracted folder:

```powershell
$repo = "C:\path\to\your\project"
$wheel = ".\persistmind-0.2.2-py3-none-any.whl"
$sha = "320cf896c91b0555cb2f3d372076fe1b2af554e68db48da4f614ec8a3a0e19a9"

.\install-persistmind.ps1 `
  -Repo $repo `
  -Agents codex `
  -BootstrapPath .\bootstrap_persistmind.py `
  -LocalWheelPath $wheel `
  -LocalWheelSha256 $sha `
  -Version 0.2.2 `
  -InitGit
```

Omit `-InitGit` if the target project is already a Git repository. Add
`-SkipIndex` for a faster install when you want to run indexing later.

After installation, open a new shell if `persistmind` is not yet on `PATH`, then
run:

```powershell
persistmind --repo $repo doctor --summary
persistmind --repo $repo codex enforcement-status
persistmind --repo $repo index
persistmind --repo $repo search "your main symbol or feature"
```

For Codex, start a new Codex session in the target project after installation so
the generated hooks and MCP configuration are loaded.

## Smoke Result

The ZIP was built from the exact source commit above. The local-wheel installer
was smoke-tested on Windows 11 with Python 3.13 against a disposable Git project.
`persistmind doctor --summary` and `persistmind codex enforcement-status` both
returned `ok: true`.

The smoke test used the candidate release identity and reported the expected
maturity warning for an unpromoted Windows Release Candidate.
